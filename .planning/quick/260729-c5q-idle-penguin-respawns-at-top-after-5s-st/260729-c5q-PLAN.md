## Locked product choices (orchestrator constraints)

- Scope: PlayScene free-roam only (`roam !== null` / after landing or crash-stop). Do not idle-respawn during ready, ramp, flight, or slide-while-moving. Pause must not advance the timer.
- Respawn = existing `resetRun()` (ramp start / ready on the log).
- Stillness = grounded and nearly still (speed below epsilon and negligible position delta). Jump, slide/walk motion, or input that changes motion resets the timer.
- MenuScene free-roam: out of scope (menu has no ramp top).
- UI: language-free circular countdown ring (fill or empty) over the last ~2000ms before respawn. Kid-readable on mobile. Prefer Graphics over Text.
- Pure TS for timer/progress; Phaser only in the scene.
- Constants: timeout 5000ms, warn window 2000ms, centralized.
- No audio, PWA, or unrelated features.
- Conventional commits; commit each task atomically.
</context>

    - shouldRespawn becomes true once idleMs reaches timeoutMs (5000)
    - warnProgress is 0 before the warn window; rises from 0 to 1 across the final warnMs (2000); at timeout warnProgress is 1
    - dtMs &lt;= 0 leaves state unchanged and shouldRespawn false
  </behavior>
  <action>

  1. Add `src/game/idleRespawn.ts` with frozen `idleRespawnDefaults`: `timeoutMs: 5000`, `warnMs: 2000`, `speedEpsilon` aligned with `freeRoamDefaults.stopSpeed` (12), `positionEpsilon` small (about 0.5 world units). Export types for sample (`eligible`, `grounded`, `speed`, `x`, `y`), state (`idleMs`, `lastX`, `lastY`), and step result (`state`, `shouldRespawn`, `warnProgress`). Export `createIdleRespawnState(x, y)` and `stepIdleRespawn(state, sample, dtMs, config = idleRespawnDefaults)`.

On accumulate, update lastX/lastY to current sample. `shouldRespawn` when idleMs &gt;= timeoutMs. `warnProgress` = clamp((idleMs - (timeoutMs - warnMs)) / warnMs, 0, 1) so the ring only advances in the final warn window.

Do not tick idle outside free-roam; paused updates already return before free-roam so the timer freezes.
