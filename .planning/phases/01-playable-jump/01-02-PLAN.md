## Trust Boundaries

| Boundary | Description |
|---|---|
| browser event stream -> InputLatch | Arbitrary timestamp values, key repeats, and multi-pointer floods approach game authority. |
| config -> numeric simulation | Tunable values can produce NaN, infinity, reversed motion, or non-terminating attempts if unchecked. |

| T-01-05 | Denial of service | event handlers | medium | mitigate | Use one pointer listener and two non-repeating key handlers; duplicate events return without allocation or state mutation. |
| T-01-06 | Tampering | `assertValidJumpConfig` and `createInitialJumpState` | medium | mitigate | Use a compile-time-exhaustive invariant matrix for every numeric JumpConfig leaf; require finite lip/geometry values, constrain minimumQuality to [0, 1], require positive spans/rates/speeds/upward components/gravity/deceleration/thresholds, enforce ordered bounds, and test NaN, both infinities, and every applicable below-range, above-range, zero, negative, or reversed-bound value before termination traces. |
