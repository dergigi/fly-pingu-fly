## Trust Boundaries

| Boundary | Description |
|---|---|
| npm registry -> local dependency tree | Third-party package contents enter the build and browser bundle. |
| browser events -> simulation command | Untrusted timestamps and repeated pointer/key events cross into authoritative game state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-SC | Tampering | npm installs | high | mitigate | Blocking package-legitimacy review, exact versions, committed `package-lock.json`, and no install before approval. |
| T-01-01 | Tampering | `PressCommand` boundary | medium | mitigate | Reject non-finite timestamps, consume at most one command, and keep simulation state browser-free. |
| T-01-02 | Denial of service | fixed-step accumulator | medium | mitigate | Clamp frame gaps and cap catch-up steps so suspension or event floods cannot create unbounded work. |
| T-01-03 | Information disclosure | static client | low | accept | No secrets, accounts, persistence, user text, or network payloads exist in this phase. |
</threat_model>
